# HivePlane v0.0.1 Tailscale Validation

Goal: run one Hive control plane and two Bee daemons on different computers, connected over Tailscale, and verify both Bees appear in Hive heartbeat state.

## Prereqs

- Both computers are on the same Tailnet.
- Each machine has Node 20+, git, and (`bee.sh` will install) pnpm.

## 1. Start the Hive

On the control-plane computer:

```bash
curl -fsSL https://raw.githubusercontent.com/AustinNChristensen/HivePlane/main/infra/install/hive.sh | sh
```

This clones the repo to `~/.hiveplane/install`, installs deps, and starts the
Hive on `0.0.0.0:8787` in the foreground. Override with `--host`/`--port` or
`--no-start`.

Find the machine's Tailscale DNS name or IP:

```bash
tailscale status
```

Your Hive URL should look like one of these:

```text
http://mac-mini.tailnet-name.ts.net:8787
http://100.x.y.z:8787
```

Quick health check from another Tailnet computer:

```bash
curl http://mac-mini.tailnet-name.ts.net:8787/healthz
```

## 2. Install Bee #1 and connect it to the Hive

On the first Bee machine:

```bash
# install (no args)
curl -fsSL http://mac-mini.tailnet-name.ts.net:8787/install/bee.sh | sh

# connect
hive login http://mac-mini.tailnet-name.ts.net:8787 --name bee-one
hive start
```

For a one-shot smoke test instead of a long-running daemon:

```bash
hive login http://mac-mini.tailnet-name.ts.net:8787 --name bee-one
hiveplane-bee --once
```

## 3. Install Bee #2 on another computer

Same flow:

```bash
curl -fsSL http://mac-mini.tailnet-name.ts.net:8787/install/bee.sh | sh
hive login http://mac-mini.tailnet-name.ts.net:8787 --name bee-two
hive start
```

## 4. Verify Hive sees both Bees

From any Tailnet computer:

```bash
curl http://mac-mini.tailnet-name.ts.net:8787/api/bees | jq
```

Expected result: two records in `bees[]`, each with `beeId`, `daemonVersion: "0.0.1"`, `status`, `lastSeenAt`, and increasing `heartbeatCount`.

## Current v0.0.1 limits

- Hive state is in-memory; restart clears connected Bee records.
- Heartbeat auth is not wired yet; Bee identity exists, but the heartbeat endpoint is intentionally open for the first networking smoke test.
- Hive returns an empty job queue. Job pickup/execution is the next milestone.
- The Bee daemon runs in the foreground via `hive start`. launchd/systemd unit
  generation is on the install-script roadmap.
