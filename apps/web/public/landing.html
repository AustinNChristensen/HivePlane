Features

Everything an agent mesh needs after the demo works once.

HivePlane is the operations layer between powerful local agents and the humans who need those agents to be accountable, observable, and recoverable.

01

Connect machines as Bees

Pair Macs, Linux boxes, servers, and home-lab machines to a self-hosted Hive over a private network path like Tailscale.

02

Capability-aware routing

Dispatch tasks based on live reported runtimes, tools, model backends, models, connectors, sessions, and working context.

03

Permissions for the real world

Model users, machines, agents, skills, tools, and risk profiles so sensitive actions can be approved, denied, audited, or kept local.

04

Jobs, artifacts, and audit history

Inspect what ran, where it ran, who requested it, which Bee handled it, what changed, and which outputs or artifacts came back.

05

Rescue agent recovery

Keep a minimal recovery layer online so Hive can restart Bees, collect logs, and run constrained repair jobs when the main agent runtime breaks.

06

Self-healing operations

Use health checks, device profiles, incident records, AI-assisted diagnosis, safe runbooks, verification jobs, and notifications to keep the swarm useful.

Who it is for

Teams that want AI close to the work.

If your agents need private repos, browsers, local files, calendars, models, CLIs, or machines you already own, HivePlane is the setup and operations layer.

1
AI-first startups and small teams

Coordinate coding agents, support agents, internal automations, and operator approvals.

2
Home labs and personal AI operators

Run multiple machines, local models, gateway processes, and personal agent workflows.

3
Companies that cannot send every job to a cloud sandbox

Keep execution near private systems while preserving policy, observability, and audit trails.

4
Builders composing multiple agent systems

Let different agents, tools, models, and connectors discover and use each other safely.

Open source

Start with the repo. Keep control of the plane.

HivePlane is Apache-2.0 and designed for self-hosted deployments first. Install a Hive, pair a Bee, run a task, and inspect the trail.
